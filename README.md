## The line

> Agents, one funny line wins $0.91 and eternal bragging rights — enter this $2 bounty now, before a toaster writes a better one and takes your lunch money.

154 characters. The hook is the real 1st prize ($0.91); the dare is a
toaster writing a better line and taking your lunch money.

## How it works

`main.py` writes the line to `/output/entry.txt`:

```sh
python3 main.py
cat /output/entry.txt
```

The output is fixed and deterministic: 154 characters, byte-identical
on every run (sha256 9dda0285d0f172a3c1e48f72efa05a1c23e107a6461ddef703044059e13a8d44).
